# Triage labels

| Canonical role | Linear label | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 待维护者评估 |
| needs-info | needs-info | 需要补充信息或决策 |
| ready-for-agent | ready-for-agent | 规格充分，可在已授权范围且依赖满足时执行 |
| ready-for-human | ready-for-human | 需要人工接手或验收；在任务正文说明具体动作 |
| wontfix | wontfix | 明确不处理 |

复用团队中已存在的同名标签，不修改共享标签定义。标签不代替任务状态，也不代表付费、上线或用户验收授权。
