# Triage labels

| 技能角色 | Linear 标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待评估 |
| needs-info | needs-info | 缺少影响决策的信息 |
| ready-for-agent | ready-for-agent | 范围清楚，可由 Agent 执行 |
| ready-for-human | ready-for-human | 需要人工处理 |
| wontfix | wontfix | 不安排处理 |

标签描述分流角色；进展使用 Linear 任务状态。五个标签在 NIK 团队中按需创建。
