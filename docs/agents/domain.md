# Domain docs

采用 single-context；根 GLOSSARY.md 与 docs/adr/ 分别维护领域术语和决策。

## 消费规则

- 探索前读取根 GLOSSARY.md，按任务读取相关 ADR；若未来存在 GLOSSARY-MAP.md，则按其指向读取相关术语表。
- GLOSSARY.md 只记录领域术语及定义，不保存实施计划、配置或任务状态。
- 沿用术语表中的规范用语；发现新概念或含混用语，在用户确认含义后更新。
- ADR 记录难以逆转、具有真实取舍的已确认决策；编号接续现有文件。
- 遇到与现有 ADR 冲突的方案，指出冲突并记录新的决策；保留历史。
- 研究证据、原型结论和实现细节放专题文档或 Linear 任务。
- 文件缺失时继续探索；仅在有明确术语或决策时创建领域文档。
