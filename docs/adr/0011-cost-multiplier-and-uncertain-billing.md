# 成本倍率计价与不明确账单的处理

用户选择统一按 4aion 成本乘倍率定价。由于公开合同尚未确认逐请求最终扣费查询，用户接受首期按已确认成本价目与实际用量计算，并支持之后与供应商真实账单核对；订单保存成本、规格、倍率及积分换算快照，复用现有平台账务机制，避免配置变化影响在途订单。

用户确认供应商可能已受理而结果不明确时，保留原任务和冻结积分进入核对，禁止自动重发；确认失败后释放，停止操作也不直接证明已取消或应退款。这优先保证任务与账务可追溯，代价是部分用户额度需要等待核对。

实施边界：[ADR-0014](0014-minimal-reuse-no-custom-systems.md)。本文规定产品目标，不代表原生已支持或授权补写机制；优先核对现有配置和操作，无法覆盖时保留待决差异。
