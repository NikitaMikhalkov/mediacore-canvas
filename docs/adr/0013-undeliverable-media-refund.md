# 最终无法交付的媒体任务退款

供应商成功收费不等于平台已向用户交付素材。用户在 Q23 选择：经过恢复后最终确认媒体无法获取、无法交付时，由平台承担该任务成本，未结算则释放冻结，已结算则通过幂等、可审计的退款流水退还用户已扣积分；同批已交付任务正常结算。

该选择使用户为可交付结果付费，代价是平台承担供应商费用与交付失败损失。一次下载失败、仍可恢复或结果未知不触发此退款；继续沿用 ADR-0011 的待核对规则，不自动重新发起付费生成。

实施边界：[ADR-0014](0014-minimal-reuse-no-custom-systems.md)。本文规定产品目标，不代表原生已支持或授权补写机制；优先核对现有配置和操作，无法覆盖时保留待决差异。
