# Mediacore 最小复用与单供应商边界

状态：已接受。

Mediacore 基于固定的影策开源版本，第一阶段复用原生账号、任务、素材、积分与界面策略，以配置和必要局部适配实现公开注册商业运营；新产品能力延至第二阶段。平台统一持有 4aion 凭据并向用户提供积分消费，所有 AI 调用仅走 4aion，避免同时维护多套用户渠道与结算边界。

这个选择牺牲了部分上游多供应商能力。若 4aion 确认不支持某项 AI 功能，首期允许明确关闭该项、保留代码与恢复条件，不通过其他供应商或本地推理绕开限制，也不把关闭项宣称为完整验收通过。普通媒体处理如 FFmpeg 继续复用。

用户可见品牌统一为 Mediacore；法定来源署名和必要内部协议标识保留，避免为改名破坏插件、数据和后续上游合并。项目与 [访谈记录](../plans/mediacore-phase1-discovery.md) 对应，任务状态以新 Linear 项目为准。
