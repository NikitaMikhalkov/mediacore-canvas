# 费用授权上限与平台差额

现有文本结算允许实际费用超过预留后形成负余额，部分音频路径则拒绝余额不足的差额结算。用户在 Q19 选择统一为事前费用授权上限：预留相应积分，用户实际扣费不超过已授权上限，超过部分记为平台差额并由平台承担；这补充 ADR-0011 的成本倍率合同，不改变未知结果保留冻结、禁止自动重发的规则。

该选择避免用户意外欠费并统一不同媒体的结算行为，代价是平台承担异常超支风险，因此需保守估算、输出预算与可审计的差额记录。不能通过事后调高授权上限来向用户转嫁差额。

实施边界：[ADR-0014](0014-minimal-reuse-no-custom-systems.md)。本文规定产品目标，不代表原生已支持或授权补写机制；优先核对现有配置和操作，无法覆盖时保留待决差异。
