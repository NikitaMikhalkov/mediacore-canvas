# Mediacore 的 4aion 原生渠道配置

一期接入沿用影策的系统渠道、官方协议插件、后台任务和积分结算。当前不新增网关、供应商插件、素材上传服务或账务模块。

## 渠道和模型

在「系统模型」创建以下渠道，密钥通过管理员界面私密填写，不写入仓库文件、浏览器普通用户配置或任务正文。`X-Aion-Model` 使用渠道已有的额外请求头编辑器设置。

| 渠道                | Base URL               | 模型 ID                           | 原生请求协议           | 额外请求头                                      |
| ------------------- | ---------------------- | --------------------------------- | ---------------------- | ----------------------------------------------- |
| 4aion 文本          | `https://4aion.com/v1` | `gpt-6.1-sol`                     | `chat-completion`      | `X-Aion-Model: gpt-6.1-sol`                     |
| 4aion 图片          | `https://4aion.com/v1` | `gpt-image-2-plus`                | `openai-image`         | `X-Aion-Model: gpt-image-2-plus`                |
| 4aion Seedance Mini | `https://4aion.com`    | `doubao-seedance-2-0-mini-260615` | `volcengine-ark-video` | `X-Aion-Model: doubao-seedance-2-0-mini-260615` |

模型使用相同的上游 ID，能力分别选择文本、图片、视频。能力参数先复用协议的原生默认值；Mini 的分辨率限定为 `480p`、`720p`，不沿用通用 Seedance 的 `1080p`。售卖规格和积分价格通过原生模型价格档配置，未确认售价的模型保持停用，不能以零价格自动开放。

额外请求头是渠道级配置：一个精确 Seedance 型号对应一个渠道，新增其他型号时复制渠道并同时修改模型 ID 和请求头；价格档也不能改成另一个上游型号。这样创建与轮询均使用相同的精确型号，不需要新增动态请求头适配代码。

管理员的「拉取模型」是只读目录查询，不能把所有返回型号自动启用。「测试模型」会真实消费供应商额度，不能当作免费的连接检查。

## 仅使用平台的 4aion 渠道

沿用现有设置：

- `PATCH /api/admin/settings/features`：`customChannelsEnabled=false`。普通用户不配置个人渠道，原生服务端守卫同时拒绝自定义调用。
- 保持原生 `frontendModelsEnabled=false`。普通用户登录后通过 `/api/model-catalog` 读取脱敏系统模型，前端已经自动转换为平台代理配置，不需要另建逻辑模型目录。`/api/channels/system` 是管理员接口，不用于验证普通用户目录。
- `PUT /api/admin/plugins/runninghub-workflow-provider/availability`：`{"available":false}`。RunningHub 工作流不受自定义渠道开关控制，须用已有的平台插件开关停用，不能留下另一家 AI 服务的入口。
- `timelineTranscriptionEnabled=false`，不配置 `CANVAS_WHISPER_BASE_URL`；本期暂不开放独立配音/字幕转写，不增加音频渠道。用户已接受先上线文本、图片和视频，音频原代码保留，等 4aion 提供可用模型后再接通。
- 方舟 IAM 可信素材库保持原生默认停用，不填写火山引擎 AK/SK，避免另行调用非 4aion 服务。

这些都是管理员配置。普通用户依然使用影策已有的账号、项目、画布、素材和积分；后台持有渠道密钥，用户目录只提供服务端代理入口。

## 视频参考素材

优先复用影策已有的短时签名素材 URL：部署设置 `CANVAS_PUBLIC_BASE_URL=https://canvas.xingcyj.com`，素材必须能从公网读取。普通素材仍由影策管理，不直接把用户私有资源变成永久公开链接。

原生 Seedance 协议可以发送图片、视频、音频 URL，并使用原生 30 秒轮询。本次不从 TF-router 搬入其独立 storage → asset 上传流程；只有某个真实请求证明签名 URL 不适用时才补必要差异。4aion 的素材接口使用 Bearer 和型号头，与上游 IAM 素材库的 AK/SK 鉴权不同，不能仅改其地址。

## 检查范围与部署交接

本次用隔离本机数据，通过原生管理员渠道接口配置、原生 `/api/tasks` 提交任务，真实调用授权为上述三个模型各一次、总预算人民币 20 元。测试库的每次 1 积分只是临时检查价格，禁止当作商业售价复制到服务器。

- 文本：收到 `OK`；图片：生成一张 PNG（1,023,720 字节），保存为平台资源并通过鉴权下载接口返回 200。
- 视频：提交参数为 4 秒、480p、1:1；4aion 已生成成功。VPN 影响本机下载，Linux 服务器读取同一结果链接返回 200；用户恢复 VPN 后，本机下载也返回 200，使用原生「重试保存」完成同一任务。平台鉴权下载返回 MP4（627,682 字节），未重新生成。
- 三条任务最终均为成功，原生账本有三条每次 1 积分的测试消费记录。供应商最终费用合计 $1.01312；按测试前保守的 10 元/美元预算口径亦低于授权的 20 元。这不是商业积分汇率。
- 原生自定义渠道守卫、系统渠道、Seedance 默认参数及可选素材同步专项检查通过。普通账号读取 `/api/model-catalog` 返回三个渠道且不含真实密钥/上游地址；自定义拉模型、个人渠道生成、转写请求均被服务端拒绝。
- 本机 SQLite 读取发生过 cgo `SIGBUS`。保留原测试数据后，将副本放在本机内置磁盘，完整性检查通过，使用已保存的供应商任务 ID 恢复查询，不重新提交生成。此操作不证明 SQLite 崩溃根因已解决；生产继续沿用原生 PostgreSQL 编排。

本次真实调用不覆盖 Agent 多步工具、全部型号、图片编辑或参考视频组合，也不宣称这些已经实测。它们继续复用上游实现，不为此另建全量验收工程。服务器部署、公开注册、正式售价、SMTP 和域名切换属于 NIK-293；本机测试配置不是生产部署。

协议依据：[4aion 开发文档](https://4aion.com/docs)、[模型价格页面](https://4aion.com/pricing)。账号只读 `/v1/models` 本次返回 54 个型号；公开网页目录和 Key 的可用目录不同，不能用未登录页面的零价格作为实际单价。
